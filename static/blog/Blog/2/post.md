기존에 이 사이트는 정적 렌더링이었습니다. Github Action + Pages로 배포했었습니다. 그런데 매번 글을 작성하려 할 때마다 노트북을 켜고 프로젝트를 열어서 마크다운 파일을 작성하고 사진 올리려면 static 폴더에다가 사진 넣고 그걸 참조하는 마크다운 요소를 집어넣고, 이렇게 어렵게 작성한 뒤에 커밋/푸쉬하고.... 확실히 기존 블로그 서비스들의 글 작성 편의성이 비교가 되지 않는다는 것을 체감했습니다.

그래서! 마침 Openrouter의 공짜 API의 성능이 어느 정도 되는지 테스트해보고 싶기도 했고, 게임기로 쓰던 윈도우 컴퓨터를 먼 곳에 두고 홈서버로 쓰게 된 김에 그냥 SSR로 재구축한 뒤 사이트에서 제가 직접 글을 관리할 수 있도록 구현하기로 했습니다.

## 1\. PLAN.md 기반 에이전트 실행

먼저 제가 원하는 기능들을 말하면서 PLAN.md를 작성하도록 시켰습니다. 그리고,

![](/blog/Blog/2/0002.png)

PLAN.md를 기반으로 앵무새처럼 다음단계 진행해달라고만 했습니다. 물론 잘 되고 있는지 중간중간 테스트해줘야 하죠.  
그러고 나서 제가 원하는 기능들을 구체적으로 지시하면서 제가 직접 수정하기도 하면서 구현했습니다.

## 2\. Cloudflare 터널링

[saens.kr](http://saens.kr) 이라는 도메인을, 제 블로그 서버가 켜져있는 곳으로 연결해주기 위해 "터널링"이라는 작업을 해줬습니다. 제 윈도우 컴퓨터는 지금 어떤 사무실 안에 있는데 해당 사무실에는 보안 처리도 되어 있고, 제 컴퓨터에 Tailscale도 작동중이라서 단순히 IP로 접속하기에는 무리가 있습니다. 그래서 터널링이라는걸 해줬습니다. 이에 대해서는 다른 글에서 자세히 다뤄보려 합니다.

## 3. 결과물

![](/blog/Blog/2/0003.png)

그렇게 이틀 정도 열심히 굴려준 결과 위처럼 이쁜 에디터 화면이 완성되었습니다! 사실 가장 원했던 건 Ctrl/Cmd + V로 사진, 음악과 같은 미디어 파일을 넣는 일이었는데, 잘 작동돼서 기분이 좋습니다.

로그인, 댓글 기능도 만들고, 자동 저장 기능도 만들고, 관리자 페이지 등등... 여러가지 기능을 추가했습니다.

이제 다음 작업들을 해야 합니다.

- SEO 설정
- 조회수 표시 기능 추가
- 좋아요 기능 추가
- 보안 점검
- 글 작성 기능 고도화
  - 링크 자동으로 생성되는거 없애기
  - 인터넷 문제로 저장기능이 작동하지 않을 때를 대비한 로컬 임시 저장 기능
  - 코드블럭 언어 선택기능
